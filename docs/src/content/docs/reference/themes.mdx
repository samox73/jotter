The [`theme`](/jotter/reference/configuration/#theme) setting picks the syntax-highlighting theme for code cells and fenced code in markdown. The rest of jOtter's interface uses your terminal's own colours, and plots [follow the terminal's colours](/jotter/guides/outputs/#plots-in-your-terminals-colours) too, so pick a theme that suits your terminal's background:

```toml title="~/.config/jotter/config.toml"
theme = "base16-ocean.light"
```
